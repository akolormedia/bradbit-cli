[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

| Path | Component |
|---|---|

| `opentui/LICENSE` | OpenTUI (MIT). |
| `opentui/LICENSE-FFMPEG` | FFmpeg license text (LGPL-2.1-or-later). |
| `opentui/FFMPEG-SOURCE.md` | FFmpeg source, version, SHA-256 and build details. |
| `opentui/LICENSE-LIBWEBP` | libwebp (BSD-3-Clause). |
| `opentui/LICENSE-LCMS2` | LittleCMS (MIT). |
| `opentui/LICENSE-GHOSTTY` | Ghostty (MIT). |
| `opentui/LICENSE-ZLIB` | zlib. |
| `opentui/LICENSE-STB` | stb (MIT). |
| `opentui/LICENSE-WUFFS` | Wuffs (Apache-2.0). |

The root [`LICENSE`](../LICENSE) is the OpenCode MIT license; the root
[`NOTICE`](../NOTICE) records the Bradbit attribution.
